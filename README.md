# RDM Super

多线程下载管理器，Windows 桌面端。由 Roivy Mao 开发。

## 功能

### 下载协议

- **HTTP 分段并行下载**：文件切块并行下载，块位图断点续传；服务器端文件变更
  自动检测（续传绝不拼出损坏文件）；被限流自动冷却退避、恢复后自动回升连接；
  服务器不支持分段时自动降级单流
- **链路自适应**：高丢包 / 不稳定链路自动降低连接数并放宽块超时（在你的
  线程数上限内只降不升），链路恢复自动回涨；小文件下载自动单流不切块
- **流媒体 HLS（m3u8）**：多码率选择、AES-128 解密、自动封装 MP4、直播追更
  （长录制滚动归档，不再堆出上万分片文件）
- **平台视频**（B站 / YouTube / 抖音 / X 等 1800+ 站点）：清晰度选择、字幕
  嵌入（全部语言）、播放列表整单下载（可设条目上限）、分片并发提速、代理
  透传、浏览器 Cookie 转发；任意视频可一键「转换为通用 MP4」；某站点连续
  解析失败且呈解析器失效形态时，失败说明会自动提示「解析器可能已过时，
  请更新软件」（网络不通 / 机器人墙 / 视频下架等不误报）
- **FTP / SFTP / FTPS**：断点续传（SFTP 带续传锚点校验）；失败自动指数退避
  重试（次数与间隔可调，凭据类永久错误不重试）
- **BT / 磁力**：磁力与种子下载，只下载不做种（完成即停止上传）；内置可
  自动更新的公开 tracker 池解决磁力冷启动，冷门资源自动延长元数据等待并
  补充 tracker；下载期间默认低速回馈上传（关闭 / 低速 / 自定义三档）
- **整站抓取**（Site Grabber）：同主机递归抓取页面与资源，深度可控（1–3 层）、
  跨主机链接排除、文件数上限保护
- **WebDAV**：`webdav://` 链接直接下载——大文件多线程分段 + 断点续传，小文件
  并发；指向目录时自动列目录并保持结构下载整个目录；任务菜单「上传到
  WebDAV」把本地文件传到坚果云等网盘
- **网盘分享链内置解析**：蓝奏云 / 奶牛快传 / 123 云盘免登录直链；百度网盘 /
  夸克网盘 / 微信公众号视频
- **专用链全面支持**（迅雷 / 快车 / QQ旋风）：粘贴、剪贴板、拖拽、浏览器插件、
  命令行与 API 全入口统一解出真实地址；时效直链过期时给出重新获取指引；
  ed2k 链接明确提示暂不支持

### AI 与模型下载

- **HuggingFace / ModelScope 整仓下载**：贴仓库页链接自动拉取文件清单整仓
  下载，保持目录结构；大文件多线程分段（独立任务、可单独重试）、小文件
  并发、失败重试只补缺失部分；受限（gated）仓库经访问令牌支持。HuggingFace
  支持模型 / 数据集 / 空间仓库（含子路径）；ModelScope 支持模型仓库，数据集
  整仓暂不支持（粘贴会明确提示，不会把网页当文件下载）
- **模型落位**：自动探测 LM Studio / Ollama / ComfyUI 的模型目录（也可自定义），
  下载完成自动按各工具的目录布局归位，可一键打开目标目录；未检测到所选
  工具时明确报错，绝不静默落错位置
- **任务级文件校验（sha256 / md5）**：校验值可手填，或由平台元数据自动带出
  （模型文件直链自动带官方 sha256）；完成时强制比对，不符自动重新下载一次，
  仍不符则拒绝标记完成并在任务列表「校验」列亮红

### 智能调度

- **磁盘空间守卫**（默认开，可关 / 调保留余量）：开始大文件下载或自动解压前
  先查目标盘剩余空间，放不下就暂停并提醒，而不是下到 95% 才把盘写满；分类
  目录所在盘放不下而默认目录放得下时自动改道并通知
- **电池模式**（默认全速，可选「自动降并发」/「电池暂停」）：拔掉电源自动
  收敛并发或暂停下载，插回自动恢复——只恢复策略暂停的任务，手动暂停的
  不动
- **计费网络感知**（默认全速）：连上蜂窝热点或在 Windows 标记了「按流量
  计费」的连接时，自动暂停超过 64MB 的大任务、新任务排队，小任务照常；
  切回不限量自动恢复；成本类型测不到时按不限量处理，绝不因探测失败停任务
- **网络分配 / 礼貌让路**（默认全速）：持续感知他源流量、前台应用（会议 /
  播放器 / 游戏）与用户在场，默认只观测不干预；选「礼貌让路」后检测到争用
  即自动限速让路、占用回落自动爬回，含「闲置全速」子选项；「手动限速」=
  自己填全局限速、零自动干预
- **转码排闲**（默认开）：有下载进行中时，「转换为通用 MP4」自动排队（先点
  先转、一次一个），下载全部结束自动开始；无下载在跑则点击即转
- **全屏勿扰**（默认开）：前台是全屏应用（游戏 / 全屏视频）时暂停全部系统
  通知与提示音——下载照常进行，只关横幅不碰下载本身

### 自动化与集成

- **完成自动化**：zip / 7z 自动解压（保留原档；rar / 带密码 / 多卷借助系统
  已安装的解压软件）；全部完成后关机 / 退出 / 执行脚本；Webhook 回调；定时
  下载；稍后下载入列；开机自启动直接进托盘
- **外部集成**：HTTP API（令牌鉴权）、aria2 JSON-RPC 兼容子集（Aria2
  Explorer / AriaNg 等现成客户端直连）、命令行 CLI（`rdm add / list / pause /
  resume / remove / status`，`--json` 机器可读输出、退出码可直接进脚本）、
  MCP 服务器（AI 助手直接派任务：任务增删查 / 暂停续、链接探测、整仓下载 +
  模型落位一步到位、全局限速）
- **JS 站点扩展**：从 URL 一键安装，为特殊站点添加解析支持（非安全边界，
  仅安装可信来源）
- **浏览器插件**（Chrome / Edge / Firefox）：网页媒体一键接管下载，网盘直链
  UA / Referer 增强

### 代理

- **代理**：HTTP CONNECT 隧道 / SOCKS5 / SOCKS4a。覆盖面（按实际）：HTTP(S)
  下载 / 流媒体 / WebDAV 与 FTP / SFTP（控制连接与数据连接均经隧道）全走
  代理；平台视频代理透传；BT 的 tracker / 网页种子 / 种子拉取走代理，并自动
  关闭绕过代理的全部 UDP 通道防真实 IP 经 UDP 泄漏——裸 peer 连接仍为直连
  （如实降级面，不承诺「所有下载类型全量走代理」）
- **直连 / 代理双路测速分流**：GitHub / HuggingFace 家族域名逐域双路探测
  可达性与时延，自动走快路（滞回防乒乓）；代理失活自动降级直连并通知，
  恢复后自动切回；双路全不可达时保持用户手动配置不改道
- **镜像健康记忆**：GitHub 加速镜像按历史成功率与时延择优排序，连续失败
  自动拉黑、夜间窗口自动复测恢复，健康账本跨重启持久化
- **站点加速**：HuggingFace 访问令牌、匿名并发截断、hf-mirror 一键切换、
  GitHub Release 资产批量下载

### 界面与易用

- **界面双语**：简体中文 / English，设置页一键切换即时生效
- **首启一次性向导**：全新装机第一次启动弹一次三步引导（默认目录确认 /
  浏览器插件安装指引 / 代理可选配置）；「跳过」与关闭等价于保持出厂默认，
  老用户升级不弹
- **主窗搜索 + 下载历史**：按名称 / URL 实时过滤任务列表；完成的下载自动
  归档历史（时间 / 大小 / 分类 / 耗时），随时回查、双击定位文件；「清空
  已完成」只清任务列表，不再抹除历史
- **拖拽与批量导入**：链接清单（txt / m3u / m3u8，每行一条；m3u 标题自动
  作为文件名）、BT 种子文件直接拖进主窗，解析去重后确认入列
- **剪贴板监听**（默认关）：复制 http / 磁力 / m3u8 / 专用链时弹托盘通知，
  点一下立即开始下载
- **同站点并发礼貌限制**：同一服务器上所有任务共享一个并发配额（默认与
  线程数一致，可调），多任务打同一站点防封
- 其他：全局限速、单任务限速与队列优先级、任务并发控制、分类目录映射、
  分段可视化进度、状态栏全局速度曲线与「当前生效状态」行、深色模式、
  通知开关与提示音、任务表列宽拖拽（持久化）、全局热键（默认关）、TLS
  指纹改道（可选）、错误行「复制完整错误 / 打开日志文件夹」取证入口

## 安全

- **凭据不落盘**：FTP / SFTP / HTTP Basic / WebDAV 凭据与解压密码一律加密
  存储（系统级凭据库），绝不写入任务与计划文件，旧版明文存量自动迁移
- **SFTP / FTPS 主机校验**：SFTP 首次连接记住主机密钥指纹（与常见 SSH 客户端
  同策），指纹变化拒绝连接并展示新旧指纹；FTPS 显式加密，服务器证书指纹
  同库校验
- **嗅探服务扩展白名单**：本地嗅探接口只信任官方浏览器扩展（白名单可在
  设置页追加），未列名扩展一律拒绝
- **敏感信息收敛**：API 令牌 / 代理密码等只在设置窗可读，其余窗口拿到的是
  剔除敏感键后的副本；崩溃报告只本地落盘不上传
- **更新安全**：应用内更新走断点续传 + 整包 SHA256 终检，更新清单带独立
  签名（公钥内置钉扎），防清单源被攻陷后整套替换安装包。安装包代码签名
  已排期（证书采购中）；当前安装包尚未签名，SmartScreen / 杀软误报属预期
  行为，处理步骤见各版本发布页说明

## 安装

1. 从 [Releases](https://github.com/roivy/rdm-super-release/releases) 下载最新的
   `RDM-Super-Setup-x.y.z.exe`
2. 双击安装（按用户安装，无需管理员权限；升级直接覆盖安装，任务与设置完整保留）
3. 开始菜单启动「RDM Super」

浏览器插件：下载 `RDM-Super-BrowserExtension-x.y.z.zip` 解压到固定目录，
`chrome://extensions` 打开开发者模式 → 加载已解压的扩展程序。

## 使用指引

- **日常下载**：点「添加 URL」粘贴链接（支持直链 / m3u8 / 磁力 / 种子 / 平台视频页链接），
  或用浏览器插件在网页里一键接管
- **进度查看**：主列表实时显示进度/速度/剩余时间；双击任务打开文件，右键更多操作；
  按住左键拖动可框选多个任务
- **设置中心**：每项配置都标了「什么时候需要动它」，一般保持默认即可
- **软件更新**：设置 → 检查更新（自动从本仓库 Releases 拉取并静默升级）
